# 卧室导航请求说明

## 1. 目标

这个示例 skill 只处理“让机器人去卧室”的动作。
它不负责状态查询、电量查询、其他地点导航，也不做多目标调度。

## 2. 请求约定

- 方法：`POST`
- 地址：`http://192.168.134.128:8080/navigate`
- 请求头：`Content-Type: application/json; charset=utf-8`
- 请求体：

```json
{
  "target": "Bedroom"
}
```

## 3. 成功处理

- 当接口返回 2xx 状态时，视为请求发送成功。
- 如果响应体是 JSON，优先原样解析并转述关键字段。
- 如果响应体不是 JSON，则返回原始文本摘要。

## 4. 失败处理

- 如果接口返回非 2xx，报告 HTTP 状态码与响应体。
- 如果网络不可达、超时或 JSON 解析失败，明确说明错误类型。
- 不要把“请求已发送”和“机器人已经到达卧室”混为一谈。

## 5. 使用边界

- 仅当用户明确表达“去卧室 / 导航到卧室 / 前往 bedroom”时使用。
- 如果用户要去厨房、阳台、花园等其他地点，明确说明这个示例 skill 不支持。
